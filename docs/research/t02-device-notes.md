## 紙面の寸法

| 項目 | 値 |
|---|---|
| 紙幅 | 約 50 mm（約 404 dot） |
| ヘッドの幅 | 384 dot（8 dot が 1 mm） |
| ヘッドのドット 0 | 紙の左端から約 16 dot（2 mm）内側 |
| 紙の右端 | ヘッドのドット 368〜387 の間で動く（機器が固定されておらず、紙に横方向の遊びがある） |
| ヘッドから切り取り位置まで | 約 7 mm（切り取った紙の上端の白） |
| `1b 64 n` | 1 単位あたり約 2 mm（16 dot） |
| 本文の下の白 | 48 行（6 mm）と CLI の紙送り 1 単位（2 mm）で 8 mm。切り取った紙の下端の白は約 1 mm |
| 本文の幅 | 368 dot をドット 2 から置く |
