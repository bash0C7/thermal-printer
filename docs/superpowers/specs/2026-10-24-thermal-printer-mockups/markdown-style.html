会議メモの markdown を、紙にどう出すのが好みですか？

実寸に近い幅（印字幅 384 dot ≒ 48mm）で、同じ markdown を 3 通りに描いています。白と黒だけ・灰色なし。気に入ったものをクリック。部分的に「A の見出し＋B のリスト」のような組み合わせも歓迎です。
